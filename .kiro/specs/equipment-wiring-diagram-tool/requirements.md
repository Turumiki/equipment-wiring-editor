# 要件文書

## 概要

Reactflowライブラリを使用して、機材の結線図を視覚的に作成・編集できるWebアプリケーションツールです。ユーザーは機材コンポーネントをドラッグ&ドロップで配置し、それらを線で接続して結線図を作成できます。

## 要件

### 要件 1

**ユーザーストーリー:** 機材管理者として、機材コンポーネントを視覚的に配置したいので、結線図を直感的に作成できるようになりたい

#### 受入基準

1. WHEN ユーザーが機材テンプレートから機材を選択 THEN システムは選択された機材をキャンバスに配置できるようにする
2. WHEN ユーザーが機材をキャンバス上でドラッグ THEN システムは機材の位置をリアルタイムで更新する
3. WHEN ユーザーが機材をダブルクリック THEN システムは機材のプロパティ編集ダイアログを表示する
4. WHEN システムが機材を表示 THEN 各機材は基本的な幾何学図形（矩形、円形、三角形など）またはカスタムアイコンで表現される
5. WHEN ユーザーが機材タイプを変更 THEN システムは対応する図形記号を自動的に更新する
6. WHEN ユーザーが機材にラベルを追加 THEN システムは図形の近くに識別テキストを表示する

### 要件 2

**ユーザーストーリー:** 技術者として、機材間の接続を線で表現したいので、結線関係を明確に可視化できるようになりたい

#### 受入基準

1. WHEN ユーザーが機材の接続ポートをクリック THEN システムは接続線の描画を開始する
2. WHEN ユーザーが別の機材の接続ポートをクリック THEN システムは2つのポート間に接続線を作成する
3. WHEN ユーザーが接続線を選択 THEN システムは接続線のプロパティ（線の種類、色、ラベル）を編集できるようにする
4. WHEN ユーザーが無効な接続を試行 THEN システムは接続を拒否し、エラーメッセージを表示する
5. WHEN システムが接続ポートを表示 THEN ハンドルは機材図形の辺上に小さな円形または四角形として表示される
6. WHEN ユーザーが機材にマウスオーバー THEN システムは利用可能な接続ポートをハイライト表示する
7. WHEN ユーザーがポート位置を調整 THEN システムは図形の辺に沿ってポートを移動できるようにする
8. WHEN 複数のポートが同じ辺にある場合 THEN システムは等間隔または指定位置に配置する

### 要件 3

**ユーザーストーリー:** プロジェクトマネージャーとして、作成した結線図を保存・読み込みしたいので、作業を継続できるようになりたい

#### 受入基準

1. WHEN ユーザーが保存ボタンをクリック THEN システムは現在の結線図をJSONファイルとして保存する
2. WHEN ユーザーがファイルを選択して読み込み THEN システムは保存された結線図を復元する
3. WHEN ユーザーが新規作成を選択 THEN システムは現在の作業をクリアして新しいキャンバスを提供する
4. WHEN ユーザーがCSVファイルをインポート THEN システムはCSVインポートウィザードを表示する
5. WHEN ユーザーがCSV列マッピングを設定 THEN システムは機材名、接続元、接続先、接続タイプなどの列を指定できるようにする
6. WHEN ユーザーがインポートを実行 THEN システムはCSVデータから結線図を自動生成する
7. IF CSVに不正なデータがある場合 THEN システムはエラー行を特定し、修正提案を表示する

### 要件 4

**ユーザーストーリー:** エンジニアとして、結線図を画像として出力したいので、ドキュメントや報告書に使用できるようになりたい

#### 受入基準

1. WHEN ユーザーがエクスポートボタンをクリック THEN システムは結線図をPNG画像として出力する
2. WHEN ユーザーがPDF出力を選択 THEN システムは結線図をPDFファイルとして出力する
3. IF 結線図が大きい場合 THEN システムは適切なスケールで出力する

### 要件 5

**ユーザーストーリー:** ユーザーとして、多様な機材タイプを使用したいので、豊富なコンポーネントライブラリを利用できるようになりたい

#### 受入基準

1. WHEN ユーザーが機材テンプレートライブラリを開く THEN システムは電源、スイッチ、センサー、コントローラーなどのカテゴリ別機材テンプレートを表示する
2. WHEN ユーザーがカスタム機材テンプレートを作成 THEN システムは新しい機材テンプレートをライブラリに保存する
3. WHEN ユーザーが機材を検索 THEN システムは名前や種類でフィルタリングされた結果を表示する

### 要件 7

**ユーザーストーリー:** ユーザーとして、オブジェクト・コンポーネントシステムを使用したいので、柔軟で拡張可能な機材定義ができるようになりたい

#### 受入基準

1. WHEN ユーザーが新しいオブジェクトを作成 THEN システムは空のゲームオブジェクト（機材オブジェクト）を生成する
2. WHEN ユーザーがオブジェクトにコンポーネントを追加 THEN システムは描画コンポーネント、接続ポートコンポーネント、プロパティコンポーネントなどを選択できるようにする
3. WHEN ユーザーが描画コンポーネントを設定 THEN システムは基本図形（矩形、円形、三角形、多角形）、色、サイズ、SVGアイコンを指定できるようにする
4. WHEN ユーザーが接続ポートコンポーネントを追加 THEN システムは新しいポートをオブジェクトに追加し、位置（上辺、下辺、左辺、右辺の指定位置またはパーセンテージ）、種類、制約を定義できるようにする
5. WHEN ユーザーが接続ポートコンポーネントを削除 THEN システムは該当ポートとそれに接続されている線を削除する
6. WHEN ユーザーが複数の接続ポートコンポーネントを追加 THEN システムは各ポートを独立したコンポーネントとして管理し、個別に設定できるようにする
7. WHEN ユーザーがプロパティコンポーネントを設定 THEN システムは名前、説明、技術仕様、カスタムフィールドを定義できるようにする
8. WHEN ユーザーがオブジェクトを選択 THEN システムはインスペクターパネルでアタッチされたコンポーネント一覧（描画、接続ポート×N個、プロパティなど）を表示する
9. WHEN ユーザーがコンポーネントを有効/無効化 THEN システムは該当機能の動作を制御する
10. WHEN ユーザーがオブジェクトをプレハブとして保存 THEN システムは再利用可能なテンプレートとしてライブラリに追加する

### 要件 6

**ユーザーストーリー:** エンジニアとして、結線情報をテーブル形式でも編集したいので、視覚的な図とデータ形式の両方で作業できるようになりたい

#### 受入基準

1. WHEN ユーザーがテーブルビューを選択 THEN システムは結線図の情報を表形式で表示する
2. WHEN ユーザーがテーブル内のセルを編集 THEN システムは変更を視覚的な結線図に即座に反映する
3. WHEN ユーザーが結線図で接続を変更 THEN システムはテーブルの対応する行を自動更新する
4. WHEN ユーザーがテーブルに新しい行を追加 THEN システムは対応する機材と接続を結線図に作成する
5. WHEN ユーザーがテーブルから行を削除 THEN システムは結線図から対応する接続を削除する
6. WHEN ユーザーがテーブルをCSVでエクスポート THEN システムは結線情報を表形式ファイルとして出力する

### 要件 8

**ユーザーストーリー:** ユーザーとして、接続ポートの位置を精密に制御したいので、ハンドルの配置を自由に調整できるようになりたい

#### 受入基準

1. WHEN ユーザーがポート編集モードを有効化 THEN システムは機材の各辺にポート追加エリアを表示する
2. WHEN ユーザーが辺上の位置をクリック THEN システムは新しいポートをその位置に作成する
3. WHEN ユーザーがポートをドラッグ THEN システムはポートを同じ辺内で移動できるようにする
4. WHEN ユーザーがポートを別の辺にドラッグ THEN システムはポートを他の辺に移動できるようにする
5. WHEN ユーザーがポート位置を数値指定 THEN システムは辺の長さに対するパーセンテージまたは絶対座標で位置を設定できるようにする
6. WHEN ユーザーがポートの向きを設定 THEN システムは内向き、外向き、双方向の接続方向を指定できるようにする
7. WHEN 複数ポートが重複する位置にある場合 THEN システムは自動的に間隔を調整するか警告を表示する

### 要件 9

**ユーザーストーリー:** ユーザーとして、作業効率を向上させたいので、便利な編集機能を使用できるようになりたい

#### 受入基準

1. WHEN ユーザーがCtrl+Zを押下 THEN システムは直前の操作を取り消す
2. WHEN ユーザーがCtrl+Yを押下 THEN システムはやり直し操作を実行する
3. WHEN ユーザーが複数の要素を選択 THEN システムは選択された要素をグループとして移動・削除できるようにする
4. WHEN ユーザーが要素をコピー&ペースト THEN システムは選択された要素を複製する
