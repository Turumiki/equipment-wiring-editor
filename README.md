# 機材結線図ツール

Reactflowを使用した機材の結線図を視覚的に作成・編集できるWebアプリケーションです。

## 主な機能

### 🎯 コア機能
- **視覚的な機材配置**: オーディオ・映像機器をドラッグ&ドロップで自由に配置
- **接続線の描画**: 機材間をポートで接続してシステム構成図を作成
- **リアルタイム編集**: 位置変更や接続変更が即座に反映

### 🔧 オブジェクト・コンポーネントシステム
- **柔軟な機材定義**: Unityスタイルのコンポーネントシステム
- **描画コンポーネント**: 矩形、円形、三角形などの基本図形
- **接続ポートコンポーネント**: 入力・出力ポートの動的追加・削除
- **プロパティコンポーネント**: 機材の名前や仕様を管理

### 📊 双方向編集
- **テーブルエディタ**: 結線情報を表形式で編集
- **リアルタイム同期**: 図とテーブルの変更が相互に反映
- **CSV出力**: 結線情報をCSV形式でエクスポート

### 📁 ファイル管理
- **プロジェクト保存・読み込み**: JSON形式でプロジェクト管理
- **CSVインポート**: 既存のCSVファイルから結線図を自動生成
- **画像・PDF出力**: PNG、JPEG、SVG、PDF形式で図面出力

### 📚 テンプレートライブラリ
- **オーディオ機器**: オーディオインターフェース、マイク、スピーカー、ヘッドフォン、Dante対応ミキサーなど
- **映像機器**: カメラ、ディスプレイ、ビデオスイッチャーなど
- **コンピューター**: パソコン、スイッチングハブなど
- **カスタムテンプレート**: 独自の機材テンプレートを作成・保存
- **カテゴリ分類**: 機材をカテゴリ別に整理

### ⚡ 高度な編集機能
- **Undo/Redo**: 操作履歴の管理（Ctrl+Z / Ctrl+Y）
- **キーボードショートカット**: 効率的な編集操作
- **複数選択**: Shiftキーで複数要素を選択
- **コピー&ペースト**: 機材の複製（Ctrl+C / Ctrl+V）
- **接続制約**: ポートタイプや方向による接続制限

## 使用方法

### 基本操作

1. **機材の追加**
   - 「テンプレート」ボタンをクリック
   - 使用したい機材を選択してキャンバスに配置

2. **機材の接続**
   - 機材のポート（小さな円）をクリック
   - 接続先のポートをクリックして線を描画

3. **プロパティ編集**
   - 機材を選択してインスペクターパネルで編集
   - 名前、位置、ポート設定などを変更

4. **テーブル編集**
   - 「テーブル」ボタンで表形式エディタを表示
   - 接続情報を直接編集可能

### キーボードショートカット

- `Ctrl+Z`: 元に戻す
- `Ctrl+Y`: やり直し
- `Ctrl+C` / `Ctrl+V`: コピー&ペースト
- `Ctrl+D`: 複製
- `Ctrl+S`: プロジェクト保存
- `Ctrl+N`: 新規プロジェクト
- `Delete`: 選択要素の削除
- `Escape`: 選択解除

### ファイル操作

- **保存**: 「保存」ボタンでJSON形式でダウンロード
- **読み込み**: 「開く」ボタンでJSONファイルを選択
- **CSVインポート**: 「CSV」ボタンで既存データをインポート
- **図面出力**: 「出力」ボタンで画像・PDF形式でエクスポート

## 技術仕様

### 使用技術
- **フロントエンド**: Next.js 15, React 18, TypeScript
- **図形描画**: ReactFlow 11
- **状態管理**: Zustand
- **スタイリング**: Tailwind CSS
- **画像出力**: html-to-image

### データ構造
- **オブジェクト・コンポーネント設計**: 柔軟で拡張可能な機材定義
- **型安全性**: TypeScriptによる厳密な型定義
- **バリデーション**: 接続制約とデータ整合性の保証

### 対応フォーマット
- **プロジェクト**: JSON
- **インポート**: CSV
- **エクスポート**: PNG, JPEG, SVG, PDF, CSV

## 開発・実行

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build

# 本番サーバー起動
npm start
```
